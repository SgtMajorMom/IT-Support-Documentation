# KB: Accessing Shared Mailboxes (M365)

## Purpose
Provide end users with clear steps to access a shared mailbox in Outlook (desktop, web, or mobile) after permissions have been granted by IT.

## When to Use This KB
Use this guide when:
- You have been granted access to a shared mailbox
- You cannot see the shared mailbox in Outlook
- You need to open a shared mailbox in Outlook Web
- You need to send email “From” the shared mailbox

---

## 1. Confirm Permissions
IT Support must grant one or both of the following:
- **Full Access** – allows opening and viewing the mailbox
- **Send As** – allows sending email as the shared mailbox

If you do not see the mailbox after following this guide, contact IT Support to confirm permissions.

---

## 2. Access the Shared Mailbox in Outlook Desktop
1. Close and reopen Outlook  
2. The shared mailbox should appear automatically in the left folder pane  
3. If it does not appear:
   - Select **File**
   - Select **Account Settings**
   - Select **Account Settings** again
   - Highlight your account and click **Change**
   - Select **More Settings**
   - Select **Advanced**
   - Click **Add**
   - Enter the shared mailbox name
   - Select **OK** and restart Outlook

---

## 3. Access the Shared Mailbox in Outlook Web (OWA)
1. Go to **https://outlook.office.com**
2. Select your profile icon (top-right)
3. Select **Open another mailbox**
4. Enter the shared mailbox name
5. Select **Open**

The shared mailbox will open in a new tab.

---

## 4. Send Email “From” the Shared Mailbox
### Outlook Desktop
1. Create a new email  
2. Select **Options**  
3. Select **From**  
4. Choose the shared mailbox from the dropdown  
5. If it does not appear:
   - Select **From**
   - Select **Other Email Address**
   - Enter the shared mailbox address

### Outlook Web
1. Create a new email  
2. Select **From**  
3. Choose the shared mailbox  
4. If not listed, select **Other email address** and enter it manually

---

## 5. Troubleshooting
- **Mailbox not appearing:**  
  Restart Outlook or sign out/sign in again  
- **Send As not working:**  
  Permissions may still be syncing (can take up to 30 minutes)  
- **Cannot open in OWA:**  
  Confirm you have **Full Access** permissions  
- **Send As denied:**  
  Confirm you have **Send As** permissions  

---

## Expected Outcome
You can successfully open, view, and send email from the shared mailbox in Outlook Desktop or Outlook Web.

## Need Help?
If the shared mailbox still does not appear, contact IT Support for verification of permissions.
